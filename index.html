Perguntas frequentes

Como funciona o sistema de recuperação de chamadas?

Quando uma chamada não é atendida, o sistema envia automaticamente uma mensagem (SMS ou WhatsApp, com consentimento) ao cliente com um link para marcar. O cliente marca online em vez de ligar a outro negócio.

Preciso de instalar alguma app ou equipamento?

Não. O sistema funciona com o teu número actual. Não precisas de mudar de operador, instalar apps nem comprar equipamento.

Quanto tempo demora a activar?

O setup completo demora entre 24 a 48 horas. Inclui configuração dos scripts de mensagem, criação da página de marcação e testes.

E se eu já usar uma app de marcações?

Perfeito — integramos com o teu sistema actual. O link de marcação pode apontar para a tua app existente. Não substituímos nada, complementamos.

E se não funcionar para o meu negócio?

Oferecemos 14 dias de teste. Se nos primeiros 14 dias não recuperares pelo menos 3 marcações, devolvemos o setup completo. Sem letras pequenas.

Tenho várias lojas — funciona em todas?

Sim. Cada loja pode ter configuração independente (scripts, horários, página de marcação). Desconto por volume para redes com 3+ localizações.
